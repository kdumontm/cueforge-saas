DSR · RGPD
Data Subject Requests (export, rectification, suppression)

Pour traiter une demande RGPD :

  1. Export des données d'un user → GET /api/v1/admin/data-cleanup/export/{user_id}
  2. Suppression complète du compte → DELETE /api/v1/admin/users/{user_id} (purge sons R2 + DB)
  3. Rectification → via édition user dans la section Users

Les actions RGPD sont tracées dans l'audit log.
